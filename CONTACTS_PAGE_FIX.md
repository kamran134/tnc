# Исправление страницы контактов в админке

## Проблема
На странице `dashboard/contacts` не отображались поля контактных сообщений от пользователей.

## Причина
Код страницы был настроен правильно, но:
1. Не учитывал все поля из бэкенда (`ContactEntity`)
2. Использовал неправильные статусы (IN_PROGRESS, RESOLVED вместо READ, REPLIED)
3. Отсутствовала страница детального просмотра контакта
4. Отсутствовали API endpoints для обновления статуса и заметок

## Что было исправлено

### 1. Обновлена главная страница контактов (`src/app/dashboard/contacts/page.tsx`)
- ✅ Исправлено отображение всех полей контакта:
  - Имя (name)
  - Email (email)
  - Телефон (phone) - с иконкой 📞
  - Компания (company) - с иконкой 🏢
  - Тема (subject)
  - Сообщение (message) - с превью
  - Дата получения (submissionDate или createdAt)
  
- ✅ Исправлены статусы согласно бэкенду:
  - NEW (Новое)
  - READ (Прочитано)
  - REPLIED (Отвечено)
  - CLOSED (Закрыто)

- ✅ Улучшено форматирование дат (dd.mm.yyyy HH:MM)
- ✅ Добавлен debug console.log для проверки структуры данных
- ✅ Переведены все тексты на русский язык
- ✅ Улучшена обработка пустых/отсутствующих полей

### 2. Создана страница детального просмотра (`src/app/dashboard/contacts/[id]/page.tsx`)
- ✅ Полное отображение всей информации о контакте
- ✅ Возможность изменения статуса контакта
- ✅ Возможность добавления/редактирования заметок администратора
- ✅ Отображение метаданных (дата получения, дата ответа, кто ответил)
- ✅ Кликабельные email и телефон
- ✅ Удобный интерфейс с боковой панелью

### 3. Созданы API endpoints

#### `/api/admin/contacts/[id]/status/route.ts`
- Обновление статуса контакта
- Метод: PATCH
- Параметры: `{ status: 'NEW' | 'READ' | 'REPLIED' | 'CLOSED' }`

#### `/api/admin/contacts/[id]/notes/route.ts`
- Сохранение заметок администратора
- Метод: PATCH
- Параметры: `{ adminNotes: string }`

#### Обновлён `/api/admin/contacts/[id]/route.ts`
- Добавлен GET метод для получения одного контакта

## Как использовать

1. **Список контактов**: `/dashboard/contacts`
   - Просмотр всех сообщений в виде таблицы
   - Фильтрация по статусу
   - Поиск по имени/email/сообщению
   - Быстрое изменение статуса из списка
   - Клик на "Просмотр" открывает детальную страницу

2. **Детальный просмотр**: `/dashboard/contacts/[id]`
   - Полная информация о контакте
   - Изменение статуса (кнопки в боковой панели)
   - Добавление/редактирование заметок администратора
   - Просмотр метаданных (даты, кто ответил)
   - Кликабельные контакты (email, телефон)
