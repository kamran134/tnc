# Локальная разработка с реальным бекендом

## Настройка

Проект настроен для работы с реальным бекендом на `https://tnc.az/api` во время локальной разработки.

### Как это работает:

1. **В режиме разработки (`npm run dev`)**:
   - Все запросы к `/api/*` автоматически проксируются на `https://tnc.az/api/*`
   - Настроено через `rewrites` в `next.config.js`
   - API клиент использует относительные пути (пустой `baseURL`)

2. **В продакшене**:
   - API клиент использует полный URL из `NEXT_PUBLIC_API_BASE_URL`
   - Нет проксирования

## Запуск

```bash
npm run dev
```

Теперь при обращении к `http://localhost:3000/api/auth/login` запрос будет проксирован на `https://tnc.az/api/auth/login`

## Проверка

После запуска `npm run dev`, попробуйте залогиниться:
- Откройте `http://localhost:3000/dashboard/login`
- Введите учетные данные
- Запросы будут идти на реальный бекенд `https://tnc.az/api`

## Файлы конфигурации

- `next.config.js` - настройка rewrites для проксирования
- `src/lib/api/client.ts` - API клиент с правильным baseURL
- `.env.local` - переменные окружения
